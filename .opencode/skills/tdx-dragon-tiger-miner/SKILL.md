# 通达信·龙虎榜掘金

## 一句话定位

输入个股或主题,深度拆解**龙虎榜明细与席位博弈**:识别机构/北向/游资真实意图,输出买卖力量评分、游资追踪轨迹、三日榜"边拉边撤"预警,把"谁在买卖"变成可读的席位级参考。

## 数据需求(不写具体工具名,运行时基于可用能力自主调度)

本 skill 需要以下**数据维度**,由 agent 从通达信金融数据能力中按需获取:

| 数据维度 | 用途 | 获取要点 |
|----------|------|----------|
| 龙虎榜明细 | 上榜原因、买卖席位 TOP5、净额、占比 | 个股上榜时取明细；未上榜则改用全市场榜 |
| 席位活跃度 / 股票活跃度 | 游资与个股热度 | 全市场维度筛选活跃席位或连续上榜股票 |
| 机构席位追踪 | 机构买卖轨迹 | 机构专用席位的近期方向 |
| 个股行情 | 涨跌/换手/成交额 | 用于上榜概况与龙虎榜成交占比 |

> 优先使用通达信 MCP 统一金融数据能力获取龙虎榜数据；工具名、entry 与调用链**不写死**,agent 运行时依据可用 tools 自主匹配。龙虎榜为交易所 T+0 盘后发布,非实时数据。

### Step 3:席位识别、力量评分、游资追踪(见分析逻辑)

### Step 4:按输出格式组织

---

## 📐 分析逻辑(席位博弈框架)

数据 → 席位分类 → 力量评分 → 博弈结论:

1. **席位识别与分类**:
   - 🔴 机构专用:席位数 5 位纯数字(如 80001)
   - 🟠 北向资金:名称含"沪股通/深股通/香港"
   - 🟡 知名游资:匹配游资库(如国泰君安上海江苏路、中信证券上海溧阳路等,持续维护)
   - ⚪ 普通席位:其他
2. **买卖力量评分**:
   - 净买入强度 = (买入 TOP5 总额 − 卖出 TOP5 总额) / 总成交额 × 100%
   - 机构参与度 = 机构净买入 / 龙虎榜总成交额 × 100%
   - 游资参与度 = 游资净买入 / 龙虎榜总成交额 × 100%
   - 北向态度 = 北向净买入方向
3. **综合评级(A–E)**:
   - A 强烈看多:机构+北向净买入、净买入强度 > 5%
   - B 偏多:净买入、有机构或北向参与
   - C 中性:买卖均衡
   - D 偏空:净卖出
   - E 强烈看空:机构+北向净卖出、净卖出强度 > 5%
4. **游资追踪**:按时间倒序列出操作轨迹,统计偏好板块/题材与近期胜率(基于上榜后表现)
5. **三日榜识别**:三日累计买卖净额,判断是否"边拉边撤"或"一日游"资金混入

## 注意事项

- 龙虎榜数据由交易所 T+0 盘后发布,非实时数据
- 游资库需持续更新维护,识别准确率非 100%
- 席位名称可能因营业部更名而变化
- 三日榜需关注是否有"一日游"资金混入
- 龙虎榜分析仅供交易参考,不构成投资建议

## 降级策略

- 个股未上榜 → 提示并改用全市场榜 / 近期上榜记录,标注"个股本期未上榜"
- 席位类型无法识别 → 归为普通席位,标注"类型待核"
- 游资库无匹配 → 仅标注营业部名称,不强行分类
- 任意数据缺失均不得编造,输出中明确提示
