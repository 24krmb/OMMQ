# 通达信·业绩预告博弈

## 一句话定位

输入一只股票的业绩信息（预告 / 快报 / 正式财报）与当前市场环境，一键生成**业绩性质判断 + 预期差分析 + 股价位置 + 核心博弈点 + 多情景推演 + 交易策略**，帮用户想清楚"超预期是否还能涨、利空出尽能否反弹"。

## 数据需求（不写具体工具名，运行时基于可用能力自主调度）

本 skill 需要以下**数据维度**，由 agent 从通达信金融数据能力中按需获取：

| 数据维度 | 用途 | 获取要点 |
|----------|------|----------|
| 业绩预告 / 快报 / 正式财报 | 性质判断基础 | 净利润、同比增速、扣非、营收、预告期间、发布日 |
| 历史股价走势与位置 | 判断是否已被提前定价 | 发布前 N 日涨跌幅、当前相对区间位置 |
| 估值分位（PE/PB 历史分位） | 估值是否透支 | 当前估值在历史区间的位置 |
| 一致预期 / 研报评级 | 相对预期差 | 市场预期值、评级分布、目标价 |
| 行业 / 板块环境 | 博弈背景 | 市场风格（成长/价值/防御）、板块情绪 |

> 优先使用通达信 MCP 金融数据能力；工具名与调用链**不写死**，agent 运行时依据可用 tools 自主匹配。用户直接提供业绩文本时，以用户文本为准并补取行情/估值维度。

## 使用流程

### Step 1：识别场景
- "XX 业绩超预期还能买吗" → 个股 + 业绩 + 博弈
- "这业绩算好还是差" → 先判性质与预期差
- "利空出尽能不能抄底" → 弱势情景 + 反弹条件

### Step 2：收齐数据维度（见上表），校验时效与完整性
- 业绩期对齐（季度/年度），避免同比错配
- 股价位置需覆盖"发布前一段"以判断是否提前定价

### Step 3：按五步框架推演
1. 判性质（明显/小幅 超预期·符合·低于预期）
2. 判是否已被交易（股价位置）
3. 识别核心博弈点（扣非/现金流/指引/估值）
4. 多情景推演（最强/中性/弱势）
5. 落到交易策略（埋伏/跟随/低吸/回避）

### Step 4：按输出模板组织报告

---

## 📐 分析逻辑（五步推演链）

核心：**预期差 + 股价位置 + 博弈路径**，不把财务分析与交易分析混为一谈。

1. **性质判断看相对预期，不看绝对增速**：明显/小幅 超预期·符合·低于预期。
2. **必须纳入股价位置**：此前已大涨 → 超预期可能提前定价；持续弱势 → 利空可能部分反映。**好业绩也可能跌**。
3. **核心博弈点决定后续**：利润高增是否可持续、扣非是否匹配、现金流是否验证、下季指引是否更重要、估值是否已透支。
4. **多情景推演**：最强（业绩+指引双强）/ 中性（业绩好但兑现一般）/ 弱势（利好兑现或细节不佳），让用户知道"超预期≠必涨"。
5. **交易策略分人群**：持仓者 / 观望者 / 激进者 / 价值投资者，结论必须结合市场风格与个股位置，且有明确交易指向性。

> 输出要求：能用表格的数据、对比、时间轴、矩阵一律用表格呈现，减少纯文字、提升信息密度。结论必须承认"好业绩也可能跌"。

## 降级策略

- 业绩预告数据缺失 → 以用户提供的业绩文本为准，标注"官方数据暂缺，以文本为准"
- 股价位置/估值分位缺失 → 博弈点分析去掉"提前定价"维度，标注"位置数据暂缺"
- 一致预期缺失 → 性质判断改用绝对增速+行业对比，标注"预期差口径暂缺"
- 任意维度失败均不得编造数据，输出中明确提示
