# 通达信·财报速读

## 一句话定位

输入一只股票(名称或代码),在 1 分钟内给出**财报关键指标速读 + 多期趋势 + 财务异常检测 + 盈利能力诊断 + 同业对标**,快速判断"这公司财务健不健康、有没有雷"。

## 数据需求(不写具体工具名,运行时基于可用能力自主调度)

本 skill 需要以下**数据维度**,由 agent 从通达信金融数据能力中按需获取:

| 数据维度 | 用途 |
|----------|------|
| 财务三表(利润表 / 资产负债表 / 现金流量表,多期) | 指标提取、趋势对比、异常检测 |
| 行业排名与同业财务 | 同业对标 |
| 实时行情(市值 / PE / PB) | 估值对标 |

> 优先使用通达信 MCP 金融数据能力；工具名与调用链**不写死**,agent 运行时依据可用 tools 自主匹配。利润表支持报告期(年度累计)与单季度两种口径,按需选取。

---

## 使用流程

### Step 1:识别标的并确认财报期
- 名称 → 代码；确认最新报告期(年报/季报)

### Step 2:拉取财务三表(多期,建议 8–12 个季度)+ 同业财务 + 行情

### Step 3:按核心子功能推演(见分析逻辑)

### Step 4:按输出模板组织报告

---

## 📐 分析逻辑(五大子功能)

### 1. 三表关键指标提取
- **利润表**:营业总收入/总成本、营业利润、利润总额、归母净利润/扣非、毛利率(计算)、净利率、三费、EPS
- **资产负债表**:总资产/净资产、资产负债率、货币资金/交易性金融资产、应收/存货、短借/长借、商誉(关注占比)
- **现金流量表**:经营/投资/筹资净额、自由现金流(经营−资本开支)、现金流/净利润(盈利质量)

### 2. 多期趋势对比
拉取最近 8–12 个季度,展示营收/利润走势与同比增速,识别趋势拐点。

### 3. 财务异常检测(七维度)
|检测维度|异常信号|风险等级|
|---------|---------|---------|
|营收利润背离|营收增但利润下滑(或反之)|⚠️⚠️|
|经营现金流|净利持续为正但经营现金流为负|⚠️⚠️⚠️|
|应收账款|应收增速 > 营收增速|⚠️⚠️|
|存货|存货周转天数大幅增加|⚠️|
|商誉|商誉占总资产 > 30%|⚠️⚠️⚠️|
|大额理财|货币资金充裕但大额短借|⚠️⚠️|
|关联交易|关联交易占比过高|⚠️|

### 4. 盈利能力诊断
- ROE 杜邦分解(净利率 × 资产周转率 × 权益乘数)
- 毛利率趋势(扩张/稳定/收窄)
- 三费占比趋势
- 盈利质量评分(经营现金流/净利润)

### 5. 同行业对标
拉取同业财务,输出行业均值与排名,定位相对位置。

## 输出模板(严格遵循)

```
## 财报速读 · {公司简称}({代码})

### 核心指标一页纸(最新报告期:{2026Q1})
|指标|数值|同比|行业均值|行业排名|
|------|------|------|---------|---------|
|营业总收入|XX亿|+X%|XX亿|N/N|
|归母净利润|XX亿|+X%|XX亿|N/N|
|毛利率|X%|+Xpp|X%|N/N|
|净利率|X%|+Xpp|X%|N/N|
|ROE|X%|+Xpp|X%|N/N|
|资产负债率|X%|-Xpp|X%|N/N|
|经营现金流/净利润|X|-|X|N/N|

### 营收与利润趋势
{最近8季度走势 + 增速}

### 盈利能力拆解
- ROE = {净利率}% × {周转率} × {杠杆倍数} = {ROE}%
- 利润驱动因素:{净利率驱动 / 周转率驱动 / 杠杆驱动}

### 财务异常检测
✅ 未发现异常信号
或
⚠️ 检测到以下异常:
1. {异常项}:{具体说明}

### 综合财务健康评分:{A/B/C/D/F}
{一句话总结财务健康状况}
```

---

## 财务健康评分体系

|评分|标准|
|------|------|
|**A(优秀)**|营收/利润持续双增,毛利率稳定或提升,经营现金流充裕,负债率健康,无异常信号|
|**B(良好)**|财务稳健,个别指标有波动但不影响大局|
|**C(一般)**|存在1-2项需关注的指标,需持续跟踪|
|**D(偏弱)**|多个核心指标恶化或存在重要异常信号|
|**F(高风险)**|财务造假嫌疑、持续亏损、资金链风险|

---

## 注意事项

- 财报数据为历史数据,反映过去经营,不代表未来
- 会计准则变化可能导致口径调整,跨期对比需注意
- 金融(银行/保险/券商)指标解读异于一般企业,需特殊对待
- 季度数据受季节性影响,建议结合年度综合判断
- 异常检测是风险提示,非确定性结论

---

## 降级策略

- 财务三表缺失 → 改用核心指标摘要或行业均值替代,标注"明细暂缺"
- 同业财务缺失 → 去掉对标列,标注"同业数据暂缺"
- 行情缺失 → 估值对标标注"暂缺"
- 任意维度失败均不得编造数据,输出中明确提示
