# 通达信·个股深度分析

> ⚠️ **风险提示**：本 skill 输出仅供研究与学习参考，**不构成任何投资建议**。投资有风险，据此操作风险自担，请结合自身风险承受能力独立决策。

## 一句话定位

输入一只 A 股（名称或代码），一键生成**结构化个股一页纸研究报告**，覆盖公司近况、核心投资逻辑、催化事件、业务拆分、产销链、财务健康、同业对比、盈利预测与估值、风险提示九大维度，把零散信息变成观点明确、信息密度高的投研结论。

## 数据需求（不写具体工具名，运行时基于可用能力自主调度）

本 skill 需要以下**数据维度**，由 agent 从通达信金融数据能力中按需获取（缺失时按降级策略回落，不写死具体工具）：

| 数据维度 | 用途 |
|----------|------|
| 实时行情（价 / 市值 / PE / PB / 量比 / 52 周高低） | 估值水位与交易状态 |
| 公司概况（主营 / 行业 / 基本面） | 定位与行业归属 |
| 财务三表（利润表 + 负债表 + 现金流，至少 4 期） | 盈利能力 / 成长性 / 现金流 / 杠杆 |
| 一致预期 / 机构评级 | 盈利预测与估值 consensus |
| 个股新闻 / 公告（近 30 条） | 近况与催化事件 |
| 行业排名 / 同业公司 | 同业对比底池 |
| 资金流向 | 交易面佐证 |
| 股东结构 | 股权集中度与质押 |

> 优先使用通达信 MCP 金融数据能力；工具名与调用链**不写死**，agent 运行时依据可用 tools 自主匹配。港股 / 美股场景若数据质量不及 A 股，应明确提示。

## 📐 分析逻辑（九维推演链）

数据 → 维度研判 → 观点结论：

1. **公司近况**（300–500 字）：近 6 个月战略动向、业务进展、重大事件，突出市场焦点
2. **核心投资逻辑**：短期（题材/催化剂，2–3 点）+ 长期（壁垒/成长驱动，2–4 点），每点须有事实数据支撑
3. **催化事件**：从新闻/公告提炼时间节点，判断影响方向与力度
4. **业务拆分**：各板块收入占比、毛利率趋势、边际变化方向
5. **产销链**：客户/供应商集中度、头部名称、合作深度、供应链风险
6. **财务健康**：盈利 / 成长 / 现金流 / 杠杆四维度综合判断
7. **同业对比**：选 4–8 家可比公司，行情+财务对比表
8. **盈利预测与估值**：汇总一致预期，PE/PB 方法给合理区间
9. **风险提示**：提炼 3–5 条核心风险

> 质量铁律：每章须「数据→判断→结论」叙事链，信息密度优先，数字带单位，禁止空话套话。

## 输出质量要求

- **对话直接输出**：报告主体仅在对话中以 Markdown 完整输出，不生成额外 .md 文件（用户偏好）
- **信息密度优先**：每章须有真实数据+具体事实，禁止空话套话
- **叙事驱动**：形成「数据→判断→结论」叙事链，不是搬运数据
- **数字带单位**：金额「亿元/万元」，比率「%」，倍数「倍/x」
- **表格对齐**：数值列统一右对齐
- **数据缺口处理**：按降级链全部尝试后仍无数据，标注「数据待补」，不得捏造
- **时效优先**：优先最新一期（年报/季报），注明截止时间
- **中文输出**：全文中文，专业术语规范

## 降级策略

- 实时行情缺失 → 改用最近交易日收盘快照 + 盘后数据
- 财务/基本面缺失 → 改用核心指标摘要或行业均值替代
- 资金/舆情缺失 → 标注"数据暂缺"，不臆测，结论降级为"信息不足"
- 一致预期机构数不足 → 注明覆盖机构数量，提示参考价值有限
- 中小市值/传统行业数据覆盖不足 → 直接走备选数据能力，不反复重试
- 任意维度失败均不得编造数据，输出中明确提示
